# Отчёт. Мониторинг метрик приложения Task Tracker

## 1. Стек

- **Приложение:** Task Tracker — управление задачами (создание, просмотр, обновление, завершение и удаление).
- **Backend:** Python, FastAPI, SQLAlchemy, PostgreSQL.
- **Frontend:** React, TypeScript, Nginx.
- **Развёртывание:** Docker, Kubernetes (minikube), Helm.
- **Мониторинг:** Victoria Metrics Single (хранение и запросы метрик), vmagent (сбор метрик и передача в хранилище).

## 2. Используемые экспортёры

| Источник          | Экспортёр                                                | Endpoint        | Примеры метрик                                                          |
|-------------------|----------------------------------------------------------|-----------------|-------------------------------------------------------------------------|
| Backend (FastAPI) | `prometheus-fastapi-instrumentator`, `prometheus-client` | `:8000/metrics` | Количество и длительность HTTP-запросов, CPU и память процесса          |
| PostgreSQL        | `prometheuscommunity/postgres-exporter` (sidecar)        | `:9187/metrics` | `pg_up`, `pg_stat_database_numbackends`, `pg_stat_database_xact_commit` |
| Nginx (frontend)  | `nginx/nginx-prometheus-exporter` (sidecar)              | `:9113/metrics` | `nginx_up`, `nginx_connections_active`, `nginx_http_requests_total`     |

PostgreSQL exporter развёрнут во втором контейнере Pod PostgreSQL. Параметры подключения берутся из Kubernetes Secret. Для Nginx включён служебный endpoint `/stub_status`, доступный экспортеру внутри Pod. Экспортёр преобразует статистику Nginx в Prometheus-совместимый формат.

## 3. Бизнес-метрики

Метрики описывают операции над задачами — основную предметную область приложения.

| Метрика                    | Тип       | Значение                                                             |
|----------------------------|-----------|----------------------------------------------------------------------|
| `tasks_created_total`      | `Counter` | Количество созданных задач                                           |
| `tasks_completed_total`    | `Counter` | Количество переходов задач в выполненное состояние                   |
| `tasks_discompleted_total` | `Counter` | Количество переходов задач из выполненного состояния в невыполненное |
| `tasks_updated_info_total` | `Counter` | Количество обновлений задач без изменения статуса выполнения         |
| `tasks_deleted_total`      | `Counter` | Количество удалённых задач                                           |

Метрики обновляются в `TaskService` после успешного выполнения операций с задачами.

При обновлении задачи учитывается переход между состояниями `is_completed`. Если статус изменился, увеличивается соответствующий счётчик. Если статус остался прежним, увеличивается tasks_updated_info_total.

Все метрики имеют тип Counter и отражают накопленное количество операций с момента запуска процесса приложения.
